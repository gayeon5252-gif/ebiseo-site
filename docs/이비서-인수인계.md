## 1. 서비스 개요

**이비서(ebiseo)** — 한국 이사 준비 전 과정을 돕는 무료 모바일 대응 웹서비스.

- 슬로건: 집을 구하는 순간부터 이사 후 정리까지, 놓치는 일 없게

- 사업 목표: 트래픽을 모아 쿠팡파트너스 수수료 + 애드센스 광고 수익

**기술 구성**

- 정적 사이트 (HTML/CSS/순수 JavaScript, 빌드 과정 없음)
- 호스팅: **Cloudflare Pages** (프로젝트명 `ebiseo`)
- 소스 관리: GitHub `gayeon5252-gif/ebiseo-site` (2026-08-18 초기 커밋, 커밋 3개)
- 로그인/DB: Supabase (구글·카카오 로그인 모두 작동)
- 분석: Google Analytics 4 (설정 문제 있음 — §8-1)
- 서버·백엔드 코드 없음. 모든 계산은 브라우저에서 실행됨.

  - **내 상황 체크 (2026-09-10 신설, `js/profile.js`)** — 히어로 바로 아래에서 청년 1인가구·신혼부부·임신 중·아기·어린이·중장년·어르신·외국인을 **여러 개** 고르면 그 상황에 맞는 제도 목록("먼저" 배지 = 우선)과 "체크리스트에 더 챙길 것"이 나온다. 선택은 `ebiseo_profile`(localStorage)에 저장되고 대시보드에 "내 상황: …" 한 줄로 표시. 사용자 요청: "체크리스트만 보이는 것보다 내 상황에 맞는 지원제도가 같이 보였으면".

## 5. 배포 방법 (Cloudflare Pages)

**확정 (2026-09-10 실측): GitHub `main`에 푸시하면 Cloudflare Pages가 자동 배포합니다.** 푸시 후 1분 안에 라이브가 바뀌는 것을 확인했습니다. 그동안 `docs/VSCODE-작업안내.md`가 "zip 수동, Git 미연결"이라고 적어 혼선이 있었는데 그 문서가 틀렸고 README가 맞았습니다 (같은 날 정정).

**현행 절차 (Git 푸시)**

1. 파일 수정 → CSS·JS를 고쳤으면 `ebiseo-tools.bat` 3번으로 캐시 버전 올리기
2. 커밋 (한글 메시지, 무엇을·왜) → `main`에 푸시
3. 1~2분 뒤 `ebiseo-tools.bat` 4번으로 라이브 점검

**따라서 푸시는 곧 공개입니다.** 확인 안 된 내용을 커밋해 두고 나중에 고치겠다는 방식은 안 됩니다 — 푸시하는 순간 방문자가 봅니다. 작업 중인 것은 커밋하지 말거나 브랜치를 따로 파세요.

**비상용 (Git이 안 될 때) — zip 수동**: `ebiseo-tools.bat` 2번 → dash.cloudflare.com → Workers & Pages → `ebiseo` → Create deployment → Production → zip → Save and deploy.

**CLI 배포도 가능**: `npx wrangler login`(브라우저 Allow 한 번) 후 `npx wrangler pages deploy public --project-name ebiseo`. 2026-09-10에 시도했으나 승인 창을 제때 못 눌러 미완. 푸시 배포가 되므로 필수 아님.

**알아두실 점**

- zip 안의 경로 구분자는 정슬래시여야 합니다. PowerShell `Compress-Archive`는 역슬래시로 넣습니다. 도구 2번을 쓰세요.
- Cloudflare 무료 플랜은 배포 월 500회, 대역폭 과금 없음.
- CSS·JS를 고쳤으면 도구 3번으로 캐시 버전을 올리세요. 안 올리면 방문자 브라우저에 옛 스크립트가 남아 화면이 깨집니다 (실제 사고 있음).
- `_headers`가 js·css를 `max-age=0, must-revalidate`로 두어 변경이 즉시 반영됩니다.
- 배포 후 확인은 Ctrl+F5.

**Netlify는 더 이상 사용하지 않습니다.** 크레딧 구조 때문에 트래픽이 늘면 멈춥니다. 2026-08-10 이전 완료. 기존 Netlify 프로젝트는 지워도 됩니다. **다만 GA4 속성에는 아직 옛 Netlify 주소가 남아 있습니다 (§8-1).**

## 10. 작업할 때 지켜온 원칙

1. **없는 것을 있는 척하지 않는다.** 가짜 업체·리뷰·제휴, 미작동 기능을 실제처럼 표시하지 않습니다. 링크가 비면 블록이 사라지도록 만든 것도 이 원칙 때문입니다.
2. **비밀키는 프런트엔드에 넣지 않는다.** service_role 키는 절대 금지.
3. **정보에는 기준일과 출처를 붙인다.** 비용·금리·법령은 "참고용이며 법률·금융 자문이 아님"을 명시.
4. **확인 못 한 것은 "확인 필요"로 표기한다.** 추측한 수치를 적지 않습니다.
5. **Cloudflare Pages 프로젝트는 `ebiseo` 하나만 쓴다.**
6. **실제로 배포하지 않았으면 배포했다고 말하지 않는다.** 배포 방식이 확정되기 전에는 푸시만으로 배포됐다고 말하지 않습니다.
7. **작업은 단계별로 나누고, 중간에 확인을 받는다.**
8. **전통 민속(길일·사주)은 예측이 아니라 참고용으로 표기한다.**
9. **개인 메일 주소를 사이트에 노출하지 않는다.**
10. **시행일이 지난 제도를 "시행 예정"으로 두지 않는다.** 확인일을 안 고치는 것도 같은 위반입니다.
