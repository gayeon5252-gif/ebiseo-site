# 이비서 (isabiseo.com)

한국 이사 준비 전 과정을 돕는 무료 정적 웹사이트입니다.

## 폴더 구조

```
public/     ← 실제로 배포되는 것만 (Cloudflare Pages 출력 폴더)
tools/      ← 운영 도구 (PowerShell). 배포되지 않습니다
docs/       ← 인수인계 문서. 배포되지 않습니다
```

**`public/` 밖의 파일은 사이트에 올라가지 않습니다.** 새 파일을 추가할 때 이 점을 지켜주세요.

## 배포

`main` 브랜치에 푸시하면 Cloudflare Pages가 자동으로 배포합니다.
다른 브랜치에 푸시하면 미리보기 주소가 따로 생기며, `isabiseo.com`에는 영향이 없습니다.

- Build command: (없음)
- Build output directory: `public`
- Production branch: `main`

비상시 수동 배포는 `tools/build-deploy.ps1`로 zip을 만들어 대시보드에 올리면 됩니다.

## 운영 도구

`ebiseo-tools.bat`을 더블클릭하면 메뉴가 뜹니다.

| 번호 | 하는 일 |
|---|---|
| 1 | 새 가이드 글 만들기 (제목만 넣으면 주소·목록·사이트맵까지 자동) |
| 2 | 배포용 zip 만들기 |
| 3 | 캐시 버전 올리기 (CSS·JS를 고쳤을 때만) |
| 4 | 라이브 사이트 점검 |

`tools/*.ps1`은 한글이 깨지지 않도록 **UTF-8 with BOM**으로 저장돼 있습니다. 편집 시 인코딩을 유지하세요.

## 글을 쓸 때 지키는 원칙

1. **없는 것을 있는 척하지 않는다** — 가짜 업체·리뷰·제휴를 만들지 않습니다.
2. **비밀키는 프런트엔드에 넣지 않는다** — Supabase service_role 키는 절대 금지. anon 키·GA4 ID·카카오 REST 키는 공개 가능한 값입니다.
3. **정보에는 확인 기준일과 출처를 붙인다** — 비용·금리·법령은 "참고용이며 법률·금융 자문이 아님"을 명시합니다.
4. **확인 못 한 것은 "확인 필요"로 표기한다** — 추측한 수치를 적지 않습니다.
5. **국회 통과 전 개정안은 "확정 아님"으로 구분한다.**

자세한 운영 정보는 `docs/` 폴더의 인수인계 문서를 보세요.
